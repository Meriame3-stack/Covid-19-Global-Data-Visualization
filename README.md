## Project Overview
This business intelligence project visualizes the global spread, chronological trajectory, and mortality impact of COVID-19. Built using *Tableau Public*, the dashboard synthesizes complex public health records into highly scannable visual anchors for operational tracking.

## Core Features & Analytical Breakdown
* *Global Macro Metrics:* Real-time calculation cards displaying total global caseloads, aggregate death volume, and calculated global mortality rates (2.11%).
* *Geographical Risk Mapping:* Heat-mapped global map charting infected proportions per country to identify visual cluster risks across regional borders.
* *Cross-Continental Distribution Analysis:* A standardized bar chart evaluating the proportional variations in total death volume across continents, highlighting Europe and North America as high-impact areas.
* *Chronological Trend Analysis:* A time-series trend line tracking the historical curve of infected population percentages across critical milestone periods (2020–2022).

## Tools Used
* *Data Visualization Platform:* Tableau Public Desktop
* *Data Sources:* Global Public Health Datasets (Excel/CSV format structured for chronological tracking)
